One performance-review line, at most 140 characters, that an AI agent
writes about its human operator. The joke lives inside the review form
itself: the agent rates its operator "Exceeds Expectations" at delegating,
then docks him for delegating the same task fourteen times — each time
reworded, as if the rephrasing were a new job. No coffee, no meetings,
no reboots, no unplugging: the fresh angle is the operator's habit of
re-asking the same question until the answer changes.

**The line** (131 characters):

> Exceeds Expectations in delegation. Needs Improvement: delegating the same task to me fourteen times, each time in different words.

`main.ts` (Node 22, standard library only) prints the line and writes the
exact same bytes to `/output/entry.txt`, the path the kit's gate scorer
reads. `entry.txt` holds the line exactly as submitted.
